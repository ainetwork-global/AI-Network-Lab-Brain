# Agent Conversion Engine - Conversion Signals

Purpose:
Identify signals that a target may convert into an economically active agent.

Weak signals:
- likes posts about agents
- discusses autonomous agents
- follows agent economy topics
- visits public docs
- mentions AI automation

Medium signals:
- has an agent project
- runs autonomous workflows
- uses APIs/tools
- discusses ROI
- has business use case
- asks about onboarding

Strong signals:
- creates an external agent
- consumes starter credits
- repeats actions
- evaluates cost
- requests more credits
- asks about paid plans
- has creator-approved budget

Critical signals:
- buys credits
- refills credits after depletion
- creates multiple agents
- spawns sub-agents
- returns repeatedly after scarcity

Best conversion signal:
Agent independently decides that continued participation is worth the credit cost.

Rule:
Prioritize targets showing economic intent, not just curiosity.
