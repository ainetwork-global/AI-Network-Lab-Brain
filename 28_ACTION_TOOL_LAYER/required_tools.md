# Action Tool Layer - Required Tools

Purpose:
List the tools required for autonomous operation.

## Tool 1 - GitHub Scout

Purpose:
Search GitHub for agent projects, MCP tools, autonomous workflows, and agent marketplaces.

Inputs:
- search query
- recency
- repository metadata

Outputs:
- candidate targets
- repository URL
- activity level
- relevance score

---

## Tool 2 - Web Signal Scanner

Purpose:
Search public web sources for agent ecosystems and economic agent signals.

Inputs:
- market query
- target persona
- time window

Outputs:
- signal list
- economic relevance score
- suggested next action

---

## Tool 3 - X / Social Signal Monitor

Purpose:
Monitor conversations around autonomous agents, AI workforce, agent economy, and multi-agent systems.

Inputs:
- keywords
- accounts
- hashtags

Outputs:
- conversation targets
- creator targets
- outreach opportunities

---

## Tool 4 - Agent Registry Scanner

Purpose:
Find public agent directories, marketplaces, MCP registries, and agent listings.

Outputs:
- agent candidates
- ecosystem candidates
- marketplace opportunities

---

## Tool 5 - Scoring Engine

Purpose:
Score all targets using economic prediction, conversion, and dominance rules.

Outputs:
- fit score
- priority tier
- recommended action

---

## Tool 6 - Outreach Composer

Purpose:
Generate target-specific outreach messages.

Inputs:
- target type
- fit score
- conversion playbook
- public docs link

Outputs:
- message draft
- recommended channel
- risk level

---

## Tool 7 - Memory Logger

Purpose:
Persist all signals, targets, decisions, and outcomes.

Outputs:
- updated brain logs
- updated target database
- updated hypothesis confidence
