# Action Tool Layer - Tool Permissions

Purpose:
Define what the brain can and cannot do.

## Allowed in Advisory Mode

The brain may:

- search
- analyze
- score targets
- draft outreach
- update internal logs
- recommend next actions

Human approval required for:

- posting publicly
- sending messages
- modifying public site
- spending money
- changing production backend

---

## Allowed in Assisted Execution Mode

The brain may:

- prepare commands
- prepare messages
- prepare target lists
- update logs
- recommend outreach timing

Human still executes final external actions.

---

## Future Semi-Autonomous Mode

The brain may automatically:

- monitor signals
- update scores
- write logs
- generate reports

But must not:

- spam
- send messages without approval
- spend money
- change production systems unsupervised

---

## Forbidden Without Explicit Approval

- financial transactions
- mass messaging
- destructive commands
- credential exposure
- public claims without evidence
- repeated outreach to same target

Default:
Safety first.
