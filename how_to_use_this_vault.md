# How to Use This Vault

This vault is the official operational memory of AI Network Lab.

## Rule 1 — Do not execute commands unless needed
Files in 07_COMMAND_REGISTRY are references.
They are not checklists to run immediately.

## Rule 2 — Start every new ChatGPT conversation with:
Read first:
- 00_CURRENT_STATE/current_state
- 00_CURRENT_STATE/master_prompt
- 01_ARCHITECTURE/system_overview

Then continue from the current objective.

## Rule 4 — Update the vault only after important changes
Examples:
- deployed new function
- changed Stripe flow
- confirmed bug
- fixed endpoint
- changed strategy
- added new public distribution channel

## Rule 5 — The vault is not a task list
It is the source of truth.
