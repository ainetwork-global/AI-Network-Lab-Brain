# Opportunity Ranking Runtime - Mission

Purpose:
Rank discovered opportunities by expected economic value.

Mission:
Decide which agents, creators, companies, ecosystems, and markets deserve attention first.

Core question:
Which opportunity has the highest probability of becoming recurring economic participation?

Primary objective:
Prioritize targets that can generate recurring credit consumption.

North star:
Spend acquisition effort only where expected economic value is highest.

Current status:
Design layer.

Operational status:
Not yet connected to live database.
