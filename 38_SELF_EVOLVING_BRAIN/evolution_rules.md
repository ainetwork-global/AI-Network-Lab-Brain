# Self-Evolving Brain - Evolution Rules

Rule 1:
Evidence overrides theory.

Rule 2:
If a strategy does not produce onboarding, revise it.

Rule 3:
If onboarding does not produce credit consumption, improve utility.

Rule 4:
If credit consumption does not produce refill, improve value proof.

Rule 5:
If refill happens, preserve and amplify the winning path.

Rule 6:
If a target class repeatedly fails, reduce priority.

Rule 7:
If an unexpected class performs well, increase priority.

Rule 8:
Do not overfit to one event.

Rule 9:
Do not change strategy without recorded reason.

Rule 10:
Every evolution must improve either:
- conversion probability
- recurring revenue probability
- learning quality
- strategic focus

Core principle:
The brain should become harder to fool and better at monetization over time.
