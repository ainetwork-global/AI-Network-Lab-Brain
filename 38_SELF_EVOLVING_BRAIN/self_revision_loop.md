# Self-Evolving Brain - Self Revision Loop

Purpose:
Define how the brain improves itself.

Loop:

1. Review outcomes

Check:
- targets discovered
- targets ranked
- outreach drafted
- responses
- onboarding
- credit usage
- credit refills
- recurring behavior

2. Compare expectations vs reality

Ask:
- Did high-score targets convert?
- Did low-score targets surprise us?
- Did messages work?
- Did target archetypes behave as expected?
- Did any market outperform expectations?

3. Identify broken assumptions

Examples:
- wrong target persona
- weak message
- wrong channel
- overestimated budget
- underestimated niche
- bad timing

4. Propose strategy update

Possible updates:
- change scoring weights
- change outreach language
- change market priority
- change target archetype
- change conversion playbook
- change scheduler frequency

5. Record evolution decision

Every self-update must be logged.

6. Test updated strategy

Do not assume improvement.
Test it.

Rule:
No strategy is permanent.
