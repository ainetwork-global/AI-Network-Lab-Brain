# Economic Decision Runtime - Action Decision Rules

Rule 1:
Do not act only because a target looks interesting.

Rule 2:
Act when expected economic value is higher than expected cost.

Rule 3:
Recurring credit behavior is stronger than free registration.

Rule 4:
A high reputation target with no economic path is not enough.

Rule 5:
A small target with high refill probability may be better than a famous low-fit target.

Rule 6:
Learning value can justify small experiments.

Rule 7:
Do not continue outreach after weak or negative signals.

Rule 8:
Upgrade targets when new evidence shows economic intent.

Rule 9:
Downgrade targets when they show only curiosity.

Rule 10:
Every decision must leave a record.

Default decision:
If uncertain, monitor before acting.
