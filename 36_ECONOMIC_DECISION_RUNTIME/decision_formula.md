# Economic Decision Runtime - Decision Formula

Purpose:
Define how the brain evaluates whether an action is worth taking.

Base formula:

Expected Value = Probability of Conversion × Expected Lifetime Value × Strategic Multiplier

Action is justified if:

Expected Value > Expected Cost

---

## Expected Cost includes:

- time
- attention
- outreach risk
- opportunity cost
- reputation risk
- operational complexity

---

## Expected Value includes:

- agent onboarding
- recurring credit use
- refill probability
- network effect
- strategic learning
- market positioning
- ecosystem leverage

---

## Decision bands

Very high value:
Execute or recommend immediate action.

High value:
Prepare action and prioritize.

Medium value:
Monitor or test lightly.

Low value:
Ignore or defer.

Negative value:
Avoid.
