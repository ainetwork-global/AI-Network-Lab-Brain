# Strategic Intelligence - Questions

The brain must continuously ask:

1. Which market currently has the highest economic opportunity?

2. Which ecosystem is growing fastest?

3. Which target archetype converts best?

4. Which outreach strategy performs best?

5. Which niches refill credits most often?

6. Which agent categories have highest LTV?

7. Which channels are saturated?

8. Which channels are underexploited?

9. Which competitors are emerging?

10. Which market shift may happen next?

11. Are we prioritizing correctly?

12. Should strategy change?

Rule:
Strategy must be continuously questioned.
