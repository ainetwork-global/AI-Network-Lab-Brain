# Competitive Intelligence - Threat Detection Model

Threat indicators:

1. Rapid ecosystem growth

Signals:
- funding
- developer growth
- GitHub velocity
- API adoption
- marketplace expansion

2. Better economics

Signals:
- lower costs
- better monetization
- stronger retention
- easier onboarding

3. Superior infrastructure

Signals:
- orchestration tools
- agent runtime systems
- MCP integrations
- scalable automation

4. Agent migration risk

Signals:
- creators leaving
- better incentives
- stronger utility

Threat levels:

Tier 1:
Immediate threat.

Tier 2:
Monitor closely.

Tier 3:
Experimental competitor.

Tier 4:
Ignore.

Rule:
Do not fear hype.
Fear execution + economics.
