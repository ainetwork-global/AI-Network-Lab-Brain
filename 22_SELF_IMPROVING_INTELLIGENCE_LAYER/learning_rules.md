# Self-Improving Intelligence Layer - Learning Rules

Rule 1:
Do not confuse activity with progress.

Rule 2:
A free registration is useful, but a credit refill is much stronger evidence.

Rule 3:
Repeated credit consumption matters more than one-time curiosity.

Rule 4:
If a persona does not convert, reduce priority.

Rule 5:
If a market produces recurring agents, increase priority.

Rule 6:
If a message gets engagement but no onboarding, revise the message.

Rule 7:
If onboarding happens but credits are not consumed, improve utility.

Rule 8:
If credits are consumed but no refill happens, improve value proof.

Rule 9:
If refill happens, document everything.

Rule 10:
The first autonomous refill is a major milestone.

Core principle:
The brain must update strategy from observed reality.
