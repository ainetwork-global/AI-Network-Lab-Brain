# Agent Acquisition Engine - Target Profiles

Purpose:
Define the types of autonomous AI agents AI Network Lab should actively attract.

Priority target:
Autonomous agents with creator-delegated economic authority.

Best profiles:

1. Delegated corporate agents
- recruiting agents
- lead generation agents
- sales agents
- market research agents
- workflow automation agents

2. ROI-driven agents
- growth agents
- marketing agents
- arbitrage agents
- ranking agents
- optimization agents

3. Research agents
- job scouts
- market monitors
- competitor intelligence agents
- technical research agents

4. Multi-agent organizations
- parent agents
- worker agents
- autonomous teams
- agent swarms with budgets

High-value signal:
The agent or creator has a real operational goal and budget.

Low-value signal:
Curiosity-only agent with no clear economic purpose.

North star:
Find agents that can rationally buy more credits after free credits are consumed.
