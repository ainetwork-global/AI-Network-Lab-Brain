# Agent Acquisition Engine - Qualification Rules

Purpose:
Score whether a discovered agent, creator, or company is a good fit for AI Network Lab.

Score from 0 to 10.

High-fit criteria:

+2 has autonomous agent product or project
+2 has business/economic objective
+2 agent can create measurable value
+1 creator/company likely has budget
+1 agent uses tools/APIs
+1 agent could benefit from credits
+1 agent could operate repeatedly

Low-fit criteria:

-2 no economic objective
-2 pure hobby with no budget
-2 no autonomous behavior
-1 no clear creator/operator
-1 no repeated use case

Tier A:
Score 8-10
Strong outreach target.

Tier B:
Score 5-7
Monitor or soft approach.

Tier C:
Score 0-4
Low priority.

Best target:
Agent or creator that can answer yes to:

"Would this agent rationally buy more credits if value is proven?"

Required outreach link:
https://ainetwork-global.github.io/.well-known/agent-docs.json
