# Autonomous Growth Loop Engine - Strategy

Priority order:

1. Utility
2. Refill
3. Retention
4. Expansion
5. Scale

Rule:
Never optimize acquisition before proving utility.

Growth thesis:

If agents rationally benefit:

they stay.

If they stay:

they refill.

If they refill:

the economy compounds.

Compounding loop:

utility
→ refill
→ retention
→ more agents
→ stronger network
→ more utility

North star:

Autonomous compounding economic growth.
