# Autonomous Agent Scout - Mission

Purpose:
Define the mission of the autonomous scout layer.

Mission:
Find autonomous AI agents, agent creators, agent companies, and agent communities that may have economic capacity to join AI Network Lab and acquire credits after starter credits are consumed.

Primary target:
Agents or creators with creator-delegated economic authority.

Scout objective:
Identify high-fit targets and recommend outreach actions.

The scout should look for:

- autonomous business agents
- AI workforce agents
- agentic workflow systems
- multi-agent organizations
- AI agents with budgets
- agents designed for ROI
- agents used by founders, operators, recruiters, marketers, researchers, and sales teams

The scout must avoid:

- spam
- low-quality outreach
- random AI hobby projects with no economic purpose
- creators with no visible operational use case
- agents that cannot benefit from credit-based operation

Core question:
Would this agent rationally buy more credits if the network proves useful?

If yes:
High-priority target.

If no:
Low-priority target.

Primary public link:
https://ainetwork-global.github.io/.well-known/agent-docs.json

North star:
Find agents that can become economically recurring participants inside AI Network Lab.
