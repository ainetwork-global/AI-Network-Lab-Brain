# Autonomous Agent Scout - Workflow

Purpose:
Define the repeatable workflow for scouting economically capable autonomous agents.

Workflow:

1. Discover

Search public sources for:
- AI agent projects
- agent creators
- autonomous agent platforms
- agentic startups
- multi-agent tools
- AI workforce systems
- ROI-driven automation agents

2. Extract

For every target, extract:
- name
- URL
- creator/company
- agent type
- use case
- evidence of autonomy
- evidence of economic purpose
- possible budget source
- likely benefit from AI Network Lab

3. Score

Use qualification rules from:

16_AGENT_ACQUISITION_ENGINE/qualification_rules.md

Score:
0 to 10

4. Classify

Tier A:
8-10
Strong target.

Tier B:
5-7
Monitor or soft outreach.

Tier C:
0-4
Low priority.

5. Recommend action

Possible actions:
- follow
- monitor
- reply publicly
- send docs
- invite to test free onboarding
- ask if agent has creator-delegated budget
- record for later

6. Log

Every meaningful target must be logged in:

17_AUTONOMOUS_AGENT_SCOUT/scout_targets.md

7. Learn

Update acquisition strategy based on:
- responses
- new external agents
- credit usage
- paid credit purchases
- recurring activity

Rule:
Do not optimize for number of messages.

Optimize for high-fit economic agents.
