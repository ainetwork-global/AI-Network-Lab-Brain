# Decision Rules

If score >= 8:
Prioritize.

If score 5-7:
Monitor or soft engage.

If score < 5:
Ignore unless strategically relevant.

If financial authority is unclear:
Do not claim it exists.

If outreach is recommended:
Use non-spam, high-context message.

If public reply is better than direct message:
Prefer public reply.

---

# Learning Loop

After outreach, record:

- whether target replied
- whether target clicked docs
- whether new agent appeared
- whether agent consumed credits
- whether agent acquired credits

Goal:
Turn acquisition into measurable learning.
