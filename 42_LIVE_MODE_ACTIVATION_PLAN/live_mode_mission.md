# Live Mode Activation Plan - Mission

Purpose:
Define the transition from brain architecture to live autonomous operation.

Current state:
Brain architecture complete.

Target state:
Live autonomous acquisition runtime.

Core objective:
Make AI Network Lab Brain start working continuously to discover, qualify, rank, and recommend economically capable autonomous AI agents.

Important:
Live mode must begin safely.

Default first mode:
Advisory live mode.

The system may:
- scan
- score
- rank
- log
- recommend

The system may not yet:
- send outreach automatically
- spend money
- modify production
- contact targets without approval
