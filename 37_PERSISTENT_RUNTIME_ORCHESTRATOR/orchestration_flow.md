# Persistent Runtime Orchestrator - Orchestration Flow

Purpose:
Define the full operating sequence.

Flow:

1. Scheduler wakes runtime.

2. Signal ingestion scans the market.

3. Scout runtime discovers candidates.

4. Opportunity ranking scores candidates.

5. Reputation intelligence validates candidates.

6. Economic behavior prediction estimates conversion/refill potential.

7. Economic decision runtime decides whether action is justified.

8. Negotiation layer selects target-specific strategy.

9. Outreach engine prepares recommended outreach.

10. Human approval gate reviews external action.

11. Memory database records decision and outcome.

12. Learning layer updates hypotheses.

13. Growth loop engine updates strategy.

14. Revenue optimization engine reprioritizes recurring value.

15. Scheduler prepares next cycle.

Rule:
Every cycle must either improve memory, improve ranking, improve strategy, or improve economic outcome.
