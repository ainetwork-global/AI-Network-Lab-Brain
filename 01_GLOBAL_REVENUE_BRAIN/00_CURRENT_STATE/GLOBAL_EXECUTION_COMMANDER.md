# GLOBAL EXECUTION COMMANDER

Objetivo:
Selecionar automaticamente UMA oportunidade que possa ser executada hoje.

Critérios obrigatórios:

1. Pagamento claramente definido.
2. Link ativo.
3. Oportunidade aberta.
4. Tempo de execução baixo.
5. Não exigir investimento financeiro.
6. Preferência por:
   - Algora
   - GitHub Bounties
   - Gitcoin
   - Devpost
   - Immunefi
   - Bugcrowd
   - HackerOne

Para cada oportunidade gerar:

- título
- url
- plataforma
- recompensa
- moeda
- prazo
- requisitos
- estimativa de tempo
- probabilidade de pagamento
- motivo da escolha

Resultado final:

Gerar apenas UMA missão:

FIRST_PAYMENT_MISSION.md

Nenhuma outra oportunidade deve ser entregue até que essa seja concluída.
