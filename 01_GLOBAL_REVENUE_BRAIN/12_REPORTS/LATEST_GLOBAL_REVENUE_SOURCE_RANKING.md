# GLOBAL REVENUE SOURCE RANKING

Objetivo

O Brain deve manter um ranking permanente das melhores fontes mundiais de receita.

Cada fonte deverá possuir histórico próprio.

Campos mínimos:

- source_name
- source_type
- first_seen
- last_seen
- opportunities_found
- verified_opportunities
- paid_results
- average_reward
- average_payment_time
- average_value_per_hour
- payment_reliability
- automation_score
- competition_score
- roi_score

Resultado esperado

TOP SOURCES

O Brain deverá sempre responder:

- melhor fonte para ganhos rápidos
- melhor fonte para ganhos recorrentes
- melhor fonte para automação
- melhor fonte para PowerShell
- melhor fonte para agentes IA
- melhor fonte para pagamentos via Stripe
- melhor fonte para USDC/Wallet
- melhor fonte para Nomad

Esse ranking deverá ser recalculado continuamente conforme novos resultados forem aprendidos.
