# Persistent Agent Memory Database - Memory Rules

Purpose:
Define what the brain must remember and how to use memory.

Rules:

1. Never forget high-value targets.

2. Do not repeatedly contact the same target without new evidence.

3. Failed outreach must be remembered.

4. Successful outreach must be converted into reusable strategy.

5. Credit refill is the strongest positive memory signal.

6. One-time free registration is weaker than recurring activity.

7. Targets with no economic path should be downgraded.

8. Repeated activity should increase priority.

9. A target that creates multiple agents should be upgraded.

10. Memory must distinguish signal from noise.

11. Every score must be revisable.

12. Evidence must override assumptions.

Core principle:
Memory is not storage.

Memory is compounding intelligence.
