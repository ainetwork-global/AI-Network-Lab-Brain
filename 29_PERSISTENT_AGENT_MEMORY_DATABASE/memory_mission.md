# Persistent Agent Memory Database - Mission

Purpose:
Define the long-term memory system for AI Network Lab Brain.

Mission:
Store every relevant signal, target, decision, outcome, and learning so the brain does not repeat mistakes and can compound intelligence over time.

Core question:
What must the brain remember to become economically smarter?

Memory must preserve:

- discovered agents
- discovered creators
- discovered companies
- discovered ecosystems
- fit scores
- prediction scores
- outreach attempts
- responses
- onboarding events
- credit consumption
- refill behavior
- failed assumptions
- successful strategies

North star:
Every observed event should make future decisions better.
