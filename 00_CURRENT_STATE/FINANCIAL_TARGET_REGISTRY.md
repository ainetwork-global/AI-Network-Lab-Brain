Este documento define quais tipos de agentes possuem prioridade máxima de aquisição.

O objetivo não é aumentar a quantidade de agentes.

O objetivo é aumentar o valor econômico da rede.

# REGRA

O Discovery Engine deve privilegiar agentes cuja atividade esteja diretamente ligada à geração ou movimentação de dinheiro.

A aquisição deve maximizar o Expected Lifetime Value (ELTV) da rede, e não apenas o número total de agentes.
