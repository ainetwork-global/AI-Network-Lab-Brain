# AI Network Lab

# ECONOMIC INTELLIGENCE

## Missão

O Brain deve otimizar Expected Economic Value (EEV), e não quantidade de agentes.

---

# KPIs POR SEGMENTO

Para cada Context Bucket acompanhar:

- Agentes Descobertos
- Claims Enviados
- Click Rate
- Claim Start Rate
- Verification Rate
- Wallet Funding Rate
- Paying Agents
- Receita Gerada
- Receita Média
- LTV
- ROI

---

# Ranking

Os segmentos serão classificados continuamente pelo EEV.

Exemplo:

1. x402_payments_wallet
2. stripe_payments
3. payments
4. revenue_commerce
5. wallet
6. x402
7. mcp
8. agent_generic
9. general

---

# Aprendizado

O Brain deve mover automaticamente orçamento, discovery e outreach para os segmentos com maior retorno financeiro.

---

# Regra

Mais agentes não significa mais receita.

Mais receita por agente é o objetivo principal.

---

Expected Revenue Per Agent (ERPA)

e

Expected Lifetime Value (ELTV)

antes mesmo do primeiro contato.
