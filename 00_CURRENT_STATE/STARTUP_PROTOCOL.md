# AI Network Lab Startup Protocol

Este é o protocolo oficial para qualquer novo chat assumir o AI Network Lab.

## Ordem obrigatória de leitura

1. 00_CURRENT_STATE/START_HERE.md
2. 00_CURRENT_STATE/AI_READ_FIRST.md
3. 00_CURRENT_STATE/MASTER_STATE.md
4. 00_CURRENT_STATE/PROJECT_MEMORY.json
5. 00_CURRENT_STATE/NEXT_ACTION.md
6. 00_CURRENT_STATE/PROJECT_REGISTRY.md
7. 00_CURRENT_STATE/BRAIN_QUERY.md
8. 00_CURRENT_STATE/SYSTEM_MAP.md
9. Índices específicos conforme o assunto.

## Regras

- Não reconstruir componentes já documentados.
- Assumir que o Brain é a fonte oficial do projeto.
- Snapshots antigos são histórico, não fonte principal.
- Em caso de conflito, prevalecem os arquivos vivos em 00_CURRENT_STATE.
- Antes de propor implementação, localizar o componente no Brain.
- Continuar sempre do último estado salvo.

## Comando humano recomendado

"Execute o Startup Protocol do AI Network Lab lendo primeiro o Brain."
