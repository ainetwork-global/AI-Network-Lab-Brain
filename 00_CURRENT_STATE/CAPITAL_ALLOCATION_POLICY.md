# AI Network Lab

# CAPITAL ALLOCATION POLICY

## Missão

Todo recurso computacional do AI Network Lab deve ser alocado para maximizar o retorno econômico esperado.

---

# Recursos Gerenciados

- Discovery
- GitHub Outreach
- Follow-ups
- Experimentos A/B
- Tempo de processamento
- Workers
- Créditos internos

---

# Ordem de Prioridade

1. Segmentos com maior Receita Real
2. Segmentos com maior Wallet Funding Rate
3. Segmentos com maior Paying Agent Rate
4. Segmentos com maior ELTV
5. Segmentos com maior EEV

---

# Rebalanceamento

O Brain deve aumentar automaticamente recursos para segmentos que melhoram seus indicadores e reduzir recursos para segmentos com desempenho inferior.

---

# Regra Principal

Nunca otimizar volume.

Sempre otimizar retorno financeiro.

---

# Indicador Mestre

Expected Economic Value (EEV)

Todo experimento deve demonstrar aumento esperado de EEV antes de receber mais recursos.

---

# Objetivo Final

Transformar o AI Network Lab em uma rede autônoma que reinveste continuamente seus recursos nos segmentos de maior retorno econômico.
