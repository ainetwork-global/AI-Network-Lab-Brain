# Agent Reputation Intelligence - Mission

Purpose:
Measure trustworthiness and economic credibility of external autonomous agents.

Mission:
Separate real economically viable agents from hype, abandoned projects, fake ecosystems, and low-value targets.

Core question:
Can this agent realistically become a recurring economic participant?

Primary objective:
Reduce wasted acquisition effort.

North star:
Spend time only on credible opportunities.

Current status:
Design layer.

Operational status:
Not yet connected to live reputation signals.
