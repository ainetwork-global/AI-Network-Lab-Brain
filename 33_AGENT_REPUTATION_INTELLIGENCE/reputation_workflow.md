# Agent Reputation Intelligence - Workflow

Purpose:
Validate discovered opportunities.

Workflow:

1. Receive ranked candidate.

2. Gather evidence:
- GitHub
- APIs
- public docs
- social presence
- founders
- company
- customers
- ecosystem mentions

3. Score reputation.

4. Detect risk:
- fake hype
- abandoned project
- weak economics
- fake autonomy
- low retention probability

5. Assign confidence:

90-100:
Highly trusted.

75-89:
Strong candidate.

55-74:
Moderate confidence.

0-54:
Weak opportunity.

6. Recommend action:
- prioritize
- monitor
- investigate deeper
- reject

7. Store memory.

Rule:
No outreach should happen before reputation validation.
