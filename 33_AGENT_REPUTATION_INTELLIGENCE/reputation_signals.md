# Agent Reputation Intelligence - Signals

Purpose:
Define trust and credibility signals.

## Technical Signals

+20 active GitHub commits
+10 working API
+10 public documentation
+10 active releases
+10 clear architecture

Negative:
-20 abandoned repository
-20 broken infrastructure
-15 no operational evidence

---

## Economic Signals

+20 paid product
+15 recurring revenue evidence
+15 paying customers
+10 marketplace activity

Negative:
-20 no monetization path
-15 unrealistic claims
-10 unclear business model

---

## Social Signals

+15 respected founder
+10 active public discussion
+10 developer adoption
+10 ecosystem mentions

Negative:
-20 fake engagement
-20 spam behavior
-15 low credibility narrative

---

## Operational Signals

+20 autonomous behavior evidence
+15 tool usage
+15 API integrations
+10 recurring workflows

Negative:
-20 manual-only system
-15 fake autonomy claims

Rule:
High noise must never outrank real operational evidence.
