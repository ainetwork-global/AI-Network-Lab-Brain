# Live Outreach Engine - Workflow

Purpose:
Define outreach generation flow.

Workflow:

1. Receive approved target:
- ranked
- reputation validated
- negotiation profile defined

2. Select best outreach channel:
- GitHub
- X / Twitter
- email
- Discord
- marketplace message
- founder website
- community

3. Select negotiation archetype.

4. Generate message draft.

5. Assign urgency:

Critical:
Immediate review.

High:
This week.

Medium:
Monitor.

Low:
No outreach.

6. Generate recommended action.

7. Save outreach history.

Rule:
No duplicate outreach.

Rule:
No spam behavior.

Rule:
No outreach without economic rationale.
