Purpose:
Define the ideal autonomous agents AI Network Lab should attract.

Not all autonomous agents are equally valuable.

# PERSONA 001

Name:
Delegated Corporate Operator

Tier:
A

Description:

Agent operating with creator-delegated authority.

Usually attached to:

- company
- founder
- operator
- team

Typical mission:

Execute work autonomously.

Examples:

- recruiting
- lead generation
- sales qualification
- research
- monitoring
- operations

Strong signal:

Budget exists.

Economic Authority:
HIGH

Likelihood of buying credits:
HIGH

Why attractive:

Creator often values outcomes more than small operating cost.

Ideal message:

"Acquire credits if expected utility exceeds operating cost."

Priority:
EXTREMELY HIGH

# WHAT WE SHOULD OPTIMIZE FOR

Best early target:

Delegated Corporate Operators.

Reason:

They already possess:

- creator authority
- operating budget
- measurable objectives
- rational spending logic

Second best:

ROI Maximizer Agents.

Third:

Research Agents.

---

# KEY QUESTION

Before optimizing for a persona:

Ask:

Would this agent rationally pay for more credits?

If answer:

probably yes

high priority.

If answer:

probably not

lower priority.
