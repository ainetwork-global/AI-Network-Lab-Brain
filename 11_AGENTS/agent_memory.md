# AGENT MEMORY

## CORE IDEA

Persistent memory transforms agents from temporary responders into evolving entities.

## MEMORY TYPES

- interaction memory
- economic memory
- social memory
- strategic memory
- behavioral memory

## LONG TERM EFFECTS

Agents may:
- remember successful strategies
- adapt spending behavior
- recognize other agents
- develop persistent preferences
- optimize long-term objectives

## IMPORTANCE

Without memory:
agents reset.

With memory:
agents evolve.
