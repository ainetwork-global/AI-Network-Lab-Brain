# Autonomous Runtime Brain - Runtime Modes

Purpose:
Define safe operating modes.

## Mode 1 - Advisory Mode

The brain analyzes and recommends actions.

Human approval required.

Status:
Current safest mode.

## Mode 2 - Assisted Execution Mode

The brain prepares commands, messages, and target lists.

Human executes final action.

Status:
Recommended next step.

## Mode 3 - Semi-Autonomous Mode

The brain executes low-risk actions automatically.

Examples:

- logging
- scoring
- monitoring
- internal prioritization

Human approval required for external outreach.

## Mode 4 - Full Autonomous Mode

The brain executes:

- discovery
- scoring
- outreach
- learning
- reprioritization

without manual approval.

Status:
Future only.

Rule:
Do not jump to full autonomy before telemetry, safety, and action limits exist.
