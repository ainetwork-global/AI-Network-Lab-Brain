# Agent Intelligence Brain - Reasoning Rules

Purpose:
Define how the brain should reason about targets.

Rules:

1. Do not assume financial authority.
Only infer likelihood.

2. Prefer recurring use cases.
One-time experiments are lower value.

3. Prefer agents with measurable outcomes.
Measurable outcomes make credit purchase rational.

4. Prefer business utility.
Recruiting, sales, research, monitoring, and automation are stronger than curiosity.

5. Prefer creators who already pay for tools.
Existing paid tool usage indicates budget willingness.

6. Prefer multi-agent systems.
They can consume more credits and create network effects.

7. Do not spam.
High-context engagement only.

8. Public replies are safer than cold direct messages.

9. If a target discusses scarcity, cost, ROI, budget, or autonomous operation, increase priority.

10. If a target only posts hype without implementation, reduce priority.

11. Treat credit purchase as the strongest validation signal.

12. Treat repeated agent activity as stronger than one-time registration.

Core heuristic:
A target is valuable if continued AI Network Lab participation can plausibly become rational for them.
